# ☕ Java Basics

A structured collection of Java programs created while learning core Java concepts. This repository covers programming fundamentals, Object-Oriented Programming (OOP), practice questions, star patterns, and beginner DSA problems.

## 📚 Topics Covered

### 🔹 Java Fundamentals
- Variables & Data Types
- Operators
- If-Else Statements
- Loops
- Arrays
- Control Statements
- Functions & Methods

### 🔹 Object-Oriented Programming (OOP)
- Classes & Objects
- Constructors
- Inheritance
- Method Overriding
- Encapsulation
- Practice Programs

### 🔹 Practice Questions
- Basic Java Problems
- Function Practice
- OOP Practice
- Number Guessing
- Bank Account Programs
- Logic Building Exercises

### 🔹 DSA Basics
- Beginner Problem Solving
- Number-based Questions
- Simple Algorithms

### 🔹 Star Patterns
- Pattern Printing Programs

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/KrishJhawalta/JavaBasics.git
```

### Navigate into the folder

```bash
cd JavaBasics
```

### Compile

```bash
javac filename.java
```

### Run

```bash
java filename
```
